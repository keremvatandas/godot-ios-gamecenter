# Store Media

`gamecenterkit-store-thumbnail.png` is the 1280 x 720 (16:9) primary Godot Asset Store
listing thumbnail. The main text and original trophy/leaderboard signal motif remain
inside a generous crop-safe margin.

The image was generated with the built-in image-generation tool, reviewed for text and
trademark constraints, then resampled from 1672 x 941 to the exact Store-ready size.
It contains no Apple logo, Game Center logo, Godot logo, App Store badge, or unrelated
brand mark.
